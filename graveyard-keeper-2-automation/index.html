Separate the worker jobs (don’t mix roles)

Fextralife Factory Automation (edited 2026-09-25) frames three distinct jobs — treat them as non-interchangeable:

Role Problem it solves Done when
Station zombie Performs the craft at a staffed bench Recipe completes on a real workstation
Zombie Supplier Station worker Keeps production stations fed without you hand-carrying every input (Zombie Assistant tech unlocks the early Supplier Station) Inputs arrive without constant babysitting
Zombie Carousel worker Provides conveyor capacity for factory belts Total capacity meets belt demand
Zombie Supply Porter Collects packed goods from Factory Supply Stations into Supply Storage Outputs clear instead of clogging supply stations

A Bioreactor-class auto-crafter is an exception (does not take a station zombie) — confirm on the building tooltip when you unlock it.

Factory layout principles

Principle Practical rule

Storage proximity Chests / Conveyor Chests within short path of stations
Single-purpose lanes Don’t cross every zombie through one chokepoint
Input → process → output order Place in flow direction
Bottleneck first Automate the station that idles you most — not “all machines at once”
Expand after stable loop Copy a working cell; don’t duplicate a jam

Power / carousel notes (capacity, not “speed gospel”)

Topic Practical rule
What power means Belt pieces, splitters, underground conveyors, and Supply Stations each add demand; Carousel workers add capacity
Capacity figures commonly cited Each active Carousel worker adds capacity (Fextralife cites 7, or 10 with Beltmaster — confirm after patches)
Spare capacity Lets you place more conveyor pieces; it does not by itself make recipes faster
Crafted “Zombie Power” items Later recipe ingredients — not the same thing as Carousel capacity

Omit “best carousel ratio” absolutes until you measure your own network.

Done when (stable loop checklist)

  • [ ] One input→station→output loop runs without you for a meaningful stretch
  • [ ] Supplier Station and/or Supply Porter roles assigned correctly for that loop
  • [ ] Carousel capacity ≥ belt demand (if using conveyors)
  • [ ] Storage placement fixed after at least one jam
  • [ ] Mistake table reviewed against your layout
  • [ ] Next expansion copied from a working cell — not a new maze
  • [ ] Worker quality improved only on bottleneck stations

FAQ

Q: When am I ready to automate vs still manually assigning?
A: When several zombies already complete jobs reliably. If assignment itself is broken, stay on the zombies hub.

Q: What do Supplier / Porter zombies do?
A: Supplier Station workers feed inputs to production; Supply Porters move packed factory supplies into Supply Storage. Carousel workers provide belt capacity — a different job.

Q: What layout mistakes break production?
A: Far storage, single mega-chest, missing porters, capacity shortfalls, expanding before one loop is stable — see mistake table.

Q: Which techs should I unlock before expanding the factory?
A: Zombie Assistant / Supplier Station first, then factory/carousel gates for the module you need — Tech Priority.

Q: How does corpse/worker quality still matter?
A: Key stations still benefit from better perk slots. Prep on Autopsy and Red Skull Zombies; don’t mass-replace every zombie at once.

Q: Where is the full zombie unlock guide?
A: Graveyard Keeper 2 Zombies — this page assumes workers exist.
