Separate the worker jobs (don’t mix roles)

Fextralife Factory Automation (edited 2026-09-25) frames distinct jobs — treat them as non-interchangeable. Tip videos agree on the same split for the iron starter line:

Role Problem it solves Done when
Station zombie (smithy / assembly) Performs the craft at a staffed bench; needs tool + mastery matching the recipe Recipe completes on a real workstation
Miner Digs iron / coal at the mine face (pickaxe) Ore piles appear for hauling
Zombie Supplier Station worker Keeps production stations fed without you hand-carrying every input (Zombie Assistant tech unlocks the early Supplier Station) Inputs arrive without constant babysitting
Zombie Carousel worker Provides conveyor capacity / factory power for belts Total capacity meets belt demand
Zombie Supply Porter Collects packed goods from Factory Supply Stations → supply pallet → warehouse corridor Outputs clear instead of clogging supply stations; porters often need no tools

A Bioreactor-class auto-crafter is an exception (does not take a station zombie) — confirm on the building tooltip when you unlock it.

Factory layout checklist

Looking for a Graveyard Keeper 2 factory layout? Prove one iron supply line first (input → smithy → assembly → supply → warehouse), keep storage close, and give each zombie a single-purpose lane before you copy the cell.

The same factory also feeds town warehouse / gratitude / commerce orders — iron supply crates are the easiest starter KPI (exact board day / qty / gratitude — confirm in UI). Still build one complete module that finishes a real pack before you expand for every order type.

First-line smoke test (iron supply)

Prove the iron supply crate path before you sprawl into wood/stone kits. Steps only — no tile coordinates. Wooden Kit I and other restoration kits are later maturity modules, not the first-line smoke test.

  1. [ ] Quest-gate conveyors — finish Jack’s Back in Business (confirm label in quest log) so the Building-tab conveyor / assembly / crate / zombie-delivery path unlocks.
  2. [ ] Clear rubble to the warehouse ladder corridor (and factory-floor rubble that blocks teleport / belt runs). Craft the clear materials in a batch if the same recipe repeats.
  3. [ ] Staff the Carousel until factory power / gear readout is positive vs demand (tip videos often cite a minimum gear reading and per-worker power — confirm the live capacity readout in UI).
  4. [ ] Miner + porter feed iron and coal into the factory input chests / belts.
  5. [ ] Short belt → smithy → assembly → supply station — iron+coal into smithy (hammer extension), ingots into assembly (iron supplies / crates), Supply Station at the end with a station worker where required.
  6. [ ] Porter → pallet → warehouse — Supply Porter grabs finished crates onto the supply pallet; long porter path reaches the town warehouse drop-off.
  7. [ ] Claim one iron order on the warehouse board on the order weekday (tip videos cite a colored order day, crate count, and gratitude reward — confirm color / qty / reward in UI). Watch one crate fulfill.

If the line stalls, jump to When the line won’t run below. After iron is stable, add wood-kit / brick-glass modules as separate cells (see Maturity).

When the line won’t run

Work this list in order. Most “broken factories” fail on role split, belt arrows, or a missing warehouse order — not on layout art.

  1. Carousel staffed / power ≥ demand? A power zombie must be on the Zombie Carousel. Capacity must cover every belt piece + Supply Station. Carousel staffed ≠ station craft running.
  2. Belt arrows & connections? Confirm the belt actually connects input → smithy → assembly → supply and that arrows face the intended flow. Wrong direction is the #1 silent break.
  3. Station has a worker? A separate craft zombie must be on the smithy / assembly. Do not expect the Carousel zombie to also craft.
  4. Mastery / tool matches recipe? Recipe may need higher Building / Metallurgy mastery or a station extension — confirm the red lock text and tool icon on the recipe (per craft: miner pickaxe, smithy hammer, assembly tool — check your build).
  5. Inputs present? Iron + coal (or other inputs) in the feeding chest / belt path; empty chest = silent stall. Conveyor chests can manually inject a few ingots to speed the first test.
  6. Recipe queued? Station has the intended recipe queued (iron supplies / crates for the smoke test — confirm recipe name; tip videos cite a fixed ingot count per crate — check your build). Wrong recipe looks like a jam. Queue a large batch so the line self-runs.
  7. Supply station + porter path open? Supply Station at the end of the line; Supply Porter → pallet → long porter corridor clear of rubble.
  8. Warehouse order actually set? On the order weekday, claim / activate the iron supply order on the warehouse board. A running factory with no active order still looks “broken” if you expected gratitude.

Role split reminder: Carousel = belt capacity; station zombie = craft; Supplier / Porter = logistics; Miner = ore. Mixing those roles is the #1 false “power” fix.

FAQ

Q: When am I ready to automate vs still manually assigning?
A: When several zombies already complete jobs reliably. If assignment itself is broken, stay on the zombies hub.

Q: What do Supplier / Porter zombies do?
A: Supplier Station workers feed inputs to production; Supply Porters move packed factory supplies into Supply Storage / the warehouse corridor. Carousel workers provide belt capacity — a different job from the station craft zombie. Staffing the Carousel does not craft crates; assign a separate station worker for that.

Q: What layout mistakes break production?
A: Far storage, single mega-chest, missing porters, capacity shortfalls, wrong belt arrows, expanding before one loop is stable — see mistake table. For a silent stall, run When the line won’t run (Carousel/power → belt arrows → station worker → mastery/tool → inputs → recipe → supply/porter path → warehouse order set).

Q: Which techs should I unlock before expanding the factory?
A: Zombie Assistant / Supplier Station first, then Jack’s Back in Business for conveyors, then smithy/assembly gates for the iron module you need — Tech Priority. Confirm Jack rep / RGB costs in UI; tip-list numbers are hints only.

Q: What’s the early factory KPI — kits or town orders?
A: Early KPI = repeatable town warehouse orders (town gratitude). Iron supply is the easiest starter module across tip videos. Tip claims for order-day color, crate count, gratitude reward, and ingots-per-crate — confirm in UI. Wood-kit and brick/glass modules come after iron is stable — principle-level only, no tile coords.

Q: How does corpse/worker quality still matter?
A: Key stations still benefit from better perk slots. Prep on Autopsy and Red Skull Zombies; don’t mass-replace every zombie at once.

Q: Carousel zombie vs station zombie — same worker?
A: No. Carousel = belt capacity; station = craft. Mixing them is why “I staffed the Carousel but nothing crafts” happens — see When the line won’t run.

Q: Where is the full zombie unlock guide?
A: Graveyard Keeper 2 Zombies — this page assumes workers exist.
